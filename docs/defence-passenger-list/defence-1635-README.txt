THE SHIP DEFENCE, 1635 — WEBSITE ARTICLE PACKAGE

Files:
  the-ship-defence-1635.html  Complete responsive, accessible standalone article with JavaScript filtering.
  defence-1635-passengers.csv  UTF-8 CSV of 87 listed passenger rows plus 15 additional identification rows.

Publishing to a static site / GitHub Pages:
1. Place the HTML file at the desired route, e.g. /articles/the-ship-defence-1635/index.html (rename the file index.html there).
2. Add an Articles index link to /articles/the-ship-defence-1635/.
3. Optionally copy the CSV to the same folder so visitors can download/search the data separately. Add a link to it as desired.
4. The HTML has inline styles/scripts and no third-party dependencies. It will work as a standalone static page, but if the website has a shared header/footer, migrate the <article> content and the scoped CSS/JS into its own page template.

The search filters all 102 rows by text (name, notes, age, grouping) and household/party. With scripting disabled, rows are still visible and browser Find works.

IMPORTANT: The original was a supplied transcription of a published compilation, not the original passenger manifest. The additional list overlaps with the main list (Shepard family). Verify all entries against printed Banks and primary documents before making stronger provenance claims.
